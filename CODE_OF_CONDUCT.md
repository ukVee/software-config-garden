# Code of conduct

This project adopts the **Contributor Covenant, version 2.1** as its code of
conduct.

The full text is published at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/> and applies
here verbatim. It is linked rather than copied so that the project cannot drift
from the canonical version by accident.

## Our standards, in one paragraph

Be decent to people. Assume good faith, criticise work rather than people, and
remember that a maintainer answering a question is doing unpaid work. Behaviour
that makes participation unsafe or unwelcome — harassment, personal attacks,
sexualised attention, deliberate intimidation, publishing someone's private
information — is not tolerated, whatever form it takes.

## Scope

This applies in every project space: issues, pull requests, discussions, commit
messages, code review, and any private communication that stems from the project.
It also applies when someone represents the project in public.

## Reporting and enforcement

**Contact: unkownvee@protonmail.com**

Report unacceptable behaviour privately to that address. Reports are read by the
maintainer only and are kept confidential; details are shared no further than
needed to act on them.

What to expect, honestly: one maintainer, best effort, no committee and no
appeal board. Enforcement follows the Contributor Covenant's ladder — a private
warning and a request to stop, then a temporary ban from interaction, then a
permanent ban — but the response is chosen to fit the behaviour rather than
mechanically. A report that concerns the maintainer's own conduct has no neutral
arbiter here; that is a real limitation of a single-maintainer project, and it is
stated rather than hidden.
